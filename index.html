Z.O.U.R. Studio

Z.O.U.R. Studio is a personal Windows desktop app for making short videos and keeping track of how they do.

What it does with TikTok

  • With the owner's permission, it reads the owner's own TikTok account numbers (followers, likes, number of videos, and each video's views, likes, comments and shares) and shows them inside the app.
  • It only reads. It does not post, comment, follow, like or message on anyone's behalf.
  • Everything it reads stays on the owner's own computer.

Who it's for

Z.O.U.R. Studio is used privately by its owner. It is not offered to the public.
